# Opening a CSV file in Excel

Unlike other methods for opening a CSV file in Excel, the following steps allow the CSV file to contain special characters like accents as well as quoted line breaks. They have been tested on macOS.
1. Launch `Excel`
2. In the `Data` menu, click `Get Data (Power Query)`
3. Select `Text/CSV`
4. Select your file
5. Click `Next`
6. Click `Load`
